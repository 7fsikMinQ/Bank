# 카드 월 실적 아이폰 위젯

BC 바로 / 네이버 현대 ED3 / 신한 / 우리다모아의 **이번 달 사용액 · 목표 달성 여부**를 아이폰 홈 화면 위젯 하나로 봅니다.
**단축어 + Scriptable(무료) + iCloud Drive**만 사용. 서버·DB·로그인·네트워크 통신 없음.

## 확정 규칙
| 카드 | 보낸 번호 | 판별 | 목표 |
|---|---|---|---|
| BC 바로 | 1588-4000 | `BC바로` | 30만 → 60만 |
| 네이버 현대 ED3 | 1577-6200 | `현대 네이버` | 40만 |
| 신한 | +82 1544-7200 | `신한카드` | 없음(0원만 아니면 달성) |
| 우리다모아 | +82 1588-9955 | `우리…` 또는 `BC체크` | 10만 |

- **월 범위**: 1일 0시 ~ 말일 23:59:59 (28/29/30/31일·윤년 자동). **문자 본문의 거래 일시**로 월을 판정(늦게 저장돼도 결제한 달), 1일이 되면 0부터 새로 시작
- 카드사 문자의 `총누적`은 그달 누적이 아니므로 **계산에 쓰지 않음**
- **취소**는 −금액, **달러 결제**는 1달러 = 1,320원 고정 환산
- 자동화는 **1개**(보낸 사람 4개 번호, 키워드 없음) + 동작 2개(텍스트 → 파일 저장)

## 파일
- `scriptable/CardWidget.single.js` : **아이폰 Scriptable에 붙여넣는 완성본** (생성물, 직접 수정 금지)
- `scriptable/ledger-core.js`, `scriptable/CardWidget.js` : 소스 → `npm run build` 로 단일 파일 생성
- `test/`, `scripts/` : `npm test` → 4개 시간대에서 전체 테스트(실제 문자·월 경계·퍼즈·보안·위젯 모의 실행·문서 동기화)

## 개발
```
npm run build   # 단일 파일 생성
npm test        # 빌드 + 전체 테스트(여러 시간대)
```
빌드 후에는 설계서 부록 코드를 `scriptable/CardWidget.single.js` 와 같게 갱신해야 `docs-sync` 테스트가 통과합니다.
