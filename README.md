# 카드 월 실적 아이폰 위젯

BC 바로 K-패스 / 네이버 현대카드 ED3 / 신한 / 우리다모아의 **이번 달 사용액 · 다음 혜택 구간**을 아이폰 홈 화면 위젯 하나로 보는 개인용 도구.
**아이폰 단축어 + Scriptable(무료) + iCloud Drive** 만 사용합니다. 서버·DB·로그인·네트워크 통신 없음.

## 확정 규칙 요약
- **월 범위**: 한국시간 **1일 00:00:00 ~ 말일 23:59:59** (28/29/30/31일, 윤년, 12→1월 자동). 매월 1일 0시에 자동 초기화.
- **카드 판별**: BC 바로 = 문자에 "비씨(BC)"+"신용" 둘 다 / 우리다모아 = "우리" 또는 "비씨(BC) 체크" / 현대 = "현대카드" / 신한 = "신한".
- **취소**: "취소" 포함 문자는 − 금액(부분취소 포함). 같은 문자가 두 자동화에 걸려도 1건으로 계산.

## 파일
- `scriptable/CardWidget.single.js` : **아이폰 Scriptable에 붙여넣는 완성본** (생성물, 직접 수정 금지)
- `scriptable/ledger-core.js`, `scriptable/CardWidget.js` : 소스. `npm run build` 로 단일 파일 생성
- `test/`, `scripts/test-all.sh` : `npm test` → 4개 시간대에서 전체 테스트(월 경계 120개월, 윤년, 카드 판별 퍼즈, 보안, 위젯 모의 실행)

## 설치가 어려우면
가이드 **§6-간단**: 단축어 자동화 1개(+취소용 1개), 동작 2개(텍스트 → 파일 저장)만으로 동작하는 간단 모드.

## 한계
실제 카드사 문자 형식·단축어 자동화의 즉시 실행 가능 여부는 아이폰에서만 확인할 수 있습니다(가이드 §7).
