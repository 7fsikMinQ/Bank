# KIGTE Claude 세션 이전 매뉴얼 (작성 2026-11-09)

이 패키지는 11/2~11/9 세션에서 확인한 내용과 기존 프로젝트 기억(메모리)을 다른 Claude 세션이나 다른 PC로 옮기기 위한 것입니다.

## 1. 패키지 구성

| 파일·폴더 | 내용 |
|---|---|
| `00_읽어주세요_이전방법_매뉴얼.md` | 이 문서. 이전 방법 |
| `01_현재상황_요약_261109.md` | 지금 상황, 열린 일, 작업 원칙 |
| `02_이사님_보고메일_최종본.txt` | 11/6 중단 보고 메일 (복사해서 바로 발송) |
| `03_서버개선제안_초안.md` | 톰캣 자동 시작·백업 개선 초안 (승인 후, 미시험) |
| `memory/` | Claude 메모리 20개 파일 (핵심) |
| `복원_가이드.md` | 개발 DB를 로컬(Windows·WSL·Docker)에 복원하는 절차 |

넣지 않은 것: 개발 DB 덤프(`kigte_dev_20261028.sql`, 약 729MB)와 계정 스크립트(`01_user.sql`). 실제 개발 데이터와 비밀번호 해시가 들어 있습니다. 대화 원문(약 638MB)도 넣지 않았습니다.

## 2. 먼저 알아 둘 것

- 메모리는 **요약본**입니다. 분석 과정, 명령 출력 원문, 메일 초안 전문은 메모리에 없습니다(메일 전문은 02번 파일에 넣었습니다).
- 이 패키지에는 **비밀번호가 없습니다**(검색으로 확인). 비밀번호는 새 세션에서도 직접 입력해야 합니다.
- 운영 정보(서버 IP, 서비스 ID, 집 공인 IP, 방화벽 허용 IP 등)는 들어 있습니다. **사내 메일이나 직접 전달로 보내고, 공개 저장소·외부 공유 링크에는 올리지 마세요.** 메일로 보낼 때는 비밀번호를 건 암호화 압축(7-Zip의 AES 등)을 권장합니다.
- 메모리의 7일 이상 지난 항목은 현재와 다를 수 있습니다. 새 세션이 확인하면서 쓰게 됩니다.

## 3. 상황 A: 같은 PC, 같은 폴더(`C:\svn\dna\work\kigte`)의 세션

옮길 것이 없습니다. 메모리는 폴더 경로에 연결되어 있어서 그 폴더에서 열린 세션이 자동으로 읽습니다.

새 세션 첫 메시지에 아래를 붙여 넣으면 상세 파일까지 확실히 읽습니다.

```
메모리의 MEMORY.md와 project_prod_reboot_20261106.md, project_home_remote_access.md, project_local_db_copy.md를 읽고, 이 패키지의 01_현재상황_요약_261109.md도 읽은 뒤 이어서 작업해 줘.
```

폴더가 다른 세션(예: 다른 폴더에서 연 세션)에는 메모리가 자동으로 가지 않습니다. 그 세션에는 아래 경로의 파일을 직접 읽으라고 시키세요(읽기 권한 확인 창이 뜰 수 있습니다).

```
C:\Users\USER\.claude\projects\C--svn-dna-work-kigte\memory\MEMORY.md
```

## 4. 상황 B: 다른 PC (예: 집 데스크탑)

1. 프로젝트 소스를 **같은 경로 `C:\svn\dna\work\kigte`**에 둡니다. 폴더 이름 `C--svn-dna-work-kigte`는 프로젝트 경로에서 만들어지므로, 경로가 다르면(예: `D:\kigte`) 폴더 이름도 달라집니다(`D--kigte`).
2. 그 폴더에서 Claude를 한 번 열었다 닫습니다. 메모리 폴더가 만들어집니다.
3. 패키지 zip을 풀어 `Downloads\KIGTE_세션이전패키지_261109`에 둡니다.
4. 대상 PC에 이미 메모리 파일이 있으면 먼저 백업합니다(없으면 건너뜁니다).

```powershell
Copy-Item "$env:USERPROFILE\.claude\projects\C--svn-dna-work-kigte\memory" "$env:USERPROFILE\.claude\projects\C--svn-dna-work-kigte\memory_backup_261109" -Recurse
```

5. 메모리를 복사합니다. 같은 이름 파일은 덮어씁니다.

```powershell
Copy-Item "$env:USERPROFILE\Downloads\KIGTE_세션이전패키지_261109\memory\*" "$env:USERPROFILE\.claude\projects\C--svn-dna-work-kigte\memory\" -Recurse
```

6. 20개가 들어갔는지 확인합니다.

```powershell
(Get-ChildItem "$env:USERPROFILE\.claude\projects\C--svn-dna-work-kigte\memory").Count
```

7. 그 폴더에서 새 세션을 열고 3장의 첫 메시지를 붙여 넣습니다.
