**남은 단계(2026-10-30 기준 목록이며, 이후 11/2에 집 IP로 22번이 열려 SSH 접속이 확인됨 — 아래 "11/2~11/6 추가" 참고)**
1. 이사님 승인(상세 메일은 "집 확인 결과"로 7장 수정 후 발송 예정, 승인 여부는 아직 모름).
2. 승인 후 Cafe24에서 **22(SSH)에만** 218.38.112.105 등록, 23306(DB)은 등록하지 않음(DB는 SSH 터널).
3. `Test-NetConnection 211.37.173.224 -Port 22` True → `ssh root@211.37.173.224`(첫 접속 지문 확인, 비밀번호는 사용자가 직접) → `who`·`lastb`·`last` 확인 → DBeaver SSH 터널 SELECT만 → 소스 앱은 `home.properties`(prod.properties 복사 후 dataSource.url만 `jdbc:mariadb://localhost:33306/kigte`, `-Dspring.profiles.active=home`, 빌드 전 삭제·커밋 금지) → 배포는 로그인·파일 목록 조회까지만.
4. 서버 지문(노트북 known_hosts): ED25519 SHA256:V5LMlKn7bHgaYvBUDeDV5GhvZK/JQ1O82REmAaKSYy8 (RSA·ECDSA 지문은 필요 시 노트북에서 `ssh-keygen -F 211.37.173.224 -l`로 확인).

**미확인**: 등록 후 실제 접속, 서버 내부 방화벽(firewalld)·hosts.allow의 IP별 제한 여부, 이 데스크탑에서 소스 앱을 터널로 띄운 시험, 실제 배포, 업체에 문의할 사항(방화벽 등록 주체, 외부 4개 IP 소유자) 답변.

**결정·원칙**: SSH 보안 강화(키 인증·root 차단)는 하지 않기로 함("기준 운영 외 다른 수정 없어야"), 대신 등록 기간 최소화·`lastb` 점검·낯선 기기 관리. 운영 서버·DB는 사용자가 허락한 작업 외에는 건드리지 않고 DB는 SELECT만. 비밀번호는 사용자가 직접 입력하고 해시·비밀번호는 메모리·메일에 적지 않는다. 상세 분석 메일(제목 `[유검평] 재택근무용 운영 서버 접속 방안 검토 결과 및 확인 요청`)은 이사님께만, 업체 문의는 이사님을 통해 전달.

**11/2~11/6 추가(세션 중 확인)**
- 22번은 집 IP(218.38.112.105)로 열려 있음: `Test-NetConnection 211.37.173.224 -Port 22`가 True, 서버 `last`에 11/2 22:40~22:56 root 로그인(집 IP) 기록, 사용자가 Termius로 접속 성공을 보고함. 등록 경위(승인 여부)는 사용자가 말하지 않아 미확인.
- 운영 DB를 DBeaver로 볼 때(SELECT 전용): MariaDB 연결의 Main은 127.0.0.1:23306/DB kigte/계정 kigte(서버에서 본 주소, 비밀번호는 사용자가 직접 입력), SSH 탭은 'Use SSH Tunnel' 체크 + 211.37.173.224:22/root/비밀번호 인증, 연결 유형 Production·Read-only 체크, `SEQ_NEXTVAL_ID` 호출 금지, 첨부 longblob 표는 SELECT * 금지. `Connection refused 127.0.0.1:23306`은 SSH 터널이 적용되지 않았다는 신호로 안내했고 사용자 쪽 해결 결과는 미확인. 대안은 `ssh -N -L 33306:127.0.0.1:23306 root@211.37.173.224` 후 DBeaver를 127.0.0.1:33306으로 연결.
- 서버 root/SSH 비밀번호는 제가 모르고 기록하지 않음(사용자가 노트북 Termius 호스트 항목에서 확인). 서버에 kigte 계정이 SSH용으로 있는지는 미확인(kigte는 DB 계정).
- Cafe24 콘솔(서비스 아이디 kigte8313 = 서버 호스트명, SSD 가상서버 자이언트플러스, Rocky 8.x, 211.37.173.224, 기간 2024.11.08~): 서버관리 메뉴는 서버관리도우미 신청·진행상황, 방화벽관리, OS재설치, 서비스 접속관리, 관리자 정보수정. '서버 재시작·작업 이력' 이름의 메뉴는 보이지 않았고, 점검 공지와 대상 확인은 help.cafe24.com 공지(점검대상 확인 페이지)에서 확인함.
