KIGTE("숙련도평가 시스템")는 한국유전자검사평가원이 유전자검사기관 품질을 관리하는 시스템. 매년 아래 순서로 진행됨.

## 4대 업무 흐름
1. **현황조사** (검사실이 기관정보·인력·시행항목 제출) →
2. **대상선정관리** (관리자가 올해 서면평가/현장평가/외부정도관리 대상 지정) →
3. 아래 3가지가 **동시 병행** 진행:
   - **서면평가**: [[pert-genesnv-architecture]] 등 "검토 및 재분류" / "적절성 평가"(PERT, `dvl.pert`) / "사전서면평가"(BFAT, `dvl.bfat`) 3갈래. 각각 심사원 배정→심사→완료 순서 동일.
   - **현장평가** (`spt`): 검사실 방문가능일 제출(최소 10일)→관리자 방문일 확정+심사원(팀장 포함) 배정→심사원 승인/협의→현장 방문·채점→**팀장 최종제출**(제출 후 수정 불가)→결과 확인/이의신청
   - **외부정도관리** (`edm`): 관리자가 평가물질/문항 준비·배포→검사실 결과 입력→관리자 예비/최종 채점→검사실 결과 확인/이의신청→통계·인증서

각 평가는 끝에 이의신청 단계가 있음(기간 내에만 가능, 관리자가 처리).

## 역할·권한 코드
| 역할 | 권한코드 | 비고 |
|---|---|---|
| 관리자(사무국) | 1000 | 전체 운영, 배정, 통계 |
| 검사실 담당자 | 2001 | 실무 전체 수행 (이의신청 포함) |
| 검사실 총괄책임자 | 2002 | 담당자와 동일 기관 상위 계정. **서면평가/현장평가/외부정도관리 "이의신청" 메뉴 접근 불가** — 이의신청 필요시 담당자 계정으로 로그인해야 함. 아이디는 담당자 아이디 앞에 "D" 접두 (예: 911E ↔ D911E) |
| 심사원 | 3001/3002/3003 | 로그인 탭 "심사원" 사용, 이메일 로그인도 가능 |
| 심사팀장/팀원 | (배정 단위, 별도 로그인 계정 아님) | 현장평가 배정 화면에서 관리자가 심사원별로 지정. 팀장만 전원 협의완료 확인 + 최종제출 권한 |

같은 메뉴/화면 주소라도 역할별로 메뉴명이 다르게 표시될 수 있음 (예: "심사 대상" = 관리자에겐 전체 목록, 심사원에겐 "심사 진행"으로 표시되지만 같은 화면).

## 계정 생성 방식
- 자가 회원가입 없음. **관리자가 먼저 계정 생성**해야 함 (검사실: 대표 홈페이지 kigte.org에서 가입 신청 → 사무국이 검토 후 시스템에 등록, 담당자+총괄책임자 쌍으로 자동 생성 / 심사원: 추천받으면 사무국이 등록, 문자·이메일 중 최소 1개로 전달).
- 최초 비밀번호 = 아이디와 동일. 검사실·심사원은 첫 로그인 시 약관동의+새 비밀번호 설정(영문+숫자 8~25자) 필수. 관리자는 약관동의 없이 비밀번호 변경만.
