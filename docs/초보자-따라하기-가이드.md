# 카드 실적 위젯 — 최종 가이드 (아이폰 16 Pro · 처음부터 끝까지)

> 컴퓨터 필요 없음. **처음 한 번 약 40~60분**, 이후엔 위젯만 보면 됩니다.
> 이 가이드의 단축어 화면 설명은 **사용자 아이폰에서 실제로 확인된 화면**(iOS 26 통합 편집기)을 기준으로 합니다. 막히면 그 화면을 캡처해서 보내 주세요(카드번호·이름은 가리고).

---

## 동작 원리 (먼저 읽기)

```
카드 문자 도착 ─▶ 단축어 자동화(바로 실행) ─▶ iCloud Drive/Scriptable/CardLedger/inbox/20261008_131014 (문자 원문 1건 = 파일 1개)
                                                        │
              위젯 갱신 / 위젯 탭 ─▶ Scriptable `CardWidget`이 inbox의 이번 달 파일을 읽어 ─▶ 카드 4개 합계 계산 ─▶ 화면에 표시
```
- 문자가 오면 **저장은 즉시, 자동**입니다(내가 할 일 없음).
- 홈 화면 위젯은 **iOS가 정하는 시점**(보통 수십 분~몇 시간)에 `CardWidget`을 실행해 다시 그립니다. 문자가 와도 위젯 숫자가 바로 바뀌지 않을 수 있습니다. 위젯 맨 아래 `갱신 14:32`가 마지막 계산 시각입니다.
- **위젯을 탭**하면 `CardWidget`이 앱에서 실행됩니다 → 진단표(어떤 문자가 어떻게 읽혔는지)가 먼저 뜨고, 닫으면 **방금 계산한 최신 위젯 미리보기**가 나옵니다. (Scriptable에는 홈 위젯을 강제로 새로고침하는 기능이 없어, 홈 화면 위젯 자체는 iOS가 다음에 갱신할 때 바뀝니다.)
- 평소엔 홈 화면 위젯을 보고, **정확한 최신 값이 필요하면 탭**합니다.
- 합계는 이번 달 문자 **전부**로 계산합니다. 진단표의 "30건"은 화면에 보이는 개수 제한일 뿐입니다.

## 0. 확정 사항

| 카드 | 보낸 번호 | 승인 문자 | 취소 문자 | 위젯 목표 |
|---|---|---|---|---|
| **BC 바로** | `+82 1588-4000` | `BC바로(…) 승인` | `BC바로(…)승인취소` | **30만 → 60만** |
| **네이버 현대 ED3** | `+82 1577-6200` | `현대 네이버 승인` | `현대 네이버 취소` | **40만** |
| **신한카드** | `+82 1544-7200` | `신한카드(…)승인` | `신한카드(…)취소` | **목표 없음 (0원만 아니면 달성)** |
| **우리다모아** | `+82 1588-9955` | `우리카드(…)체크승인` / `우리카드(…) 승인` (또는 `BC체크…`) | `우리카드(…)승인취소` | **10만** |

- **보낸 번호는 4개 모두 `+82`를 붙인 형태로 통일해 적었습니다**: BC바로 `+82 1588-4000`, 현대 `+82 1577-6200`, 신한 `+82 1544-7200`, 우리 `+82 1588-9955`. 메시지 앱에 보이는 표시가 `+82` 없이 `1588`로 시작하는 번호만 보이는 카드는 **그 화면에 보이는 그대로** 연락처에 저장하세요(표시와 연락처 번호가 같아야 자동화가 켜집니다). 위젯의 카드 판별은 번호가 아니라 문자 본문(`BC바로`, `현대 네이버`, `신한카드`, `우리…`)으로 하므로, 번호는 자동화 실행 조건에만 쓰입니다.
- 우리다모아는 "우리카드…"와 "BC 체크…" **두 표기 모두** 우리로 합산합니다.
- **월 범위: 매월 1일 0시 ~ 말일 23:59:59** (28/29/30/31일·윤년 자동). 1일이 되면 그달 합계는 0부터 새로 시작합니다.
- 어느 달에 넣을지는 **문자 본문의 거래 일시**(예: `10/31 23:59`)로 정합니다 → 저장이 늦어져도 결제한 달에 들어갑니다.
- 카드사 문자의 **`총누적`/`누적` 금액은 계산에 쓰지 않습니다**(그달 누적이 아님). 승인(+)과 취소(−)만 더합니다.
- **달러 결제**: 원 금액이 없고 `22.00 달러`처럼 오면 **1달러 = 1,320원**으로 환산합니다.
- 서버·DB·로그인·인터넷 전송 없음. 문자는 내 아이폰과 내 iCloud 안에서만 움직입니다.

`⚠︎N`(제목 옆) = 금액을 못 읽은 문자 N건(달러 외 통화 등)

## 1. 도구 (모두 무료)
**메시지**(기본) · **단축어**(기본, 보라/분홍 아이콘) · **파일**(기본) · **Scriptable**(App Store, 개발자 Simon Støvring). Scriptable과 단축어는 **서로 다른 앱**입니다.

## 2. 아이폰 점검 (5분)
1. 설정 → 일반 → 정보: iOS 18 이상 (낮으면 소프트웨어 업데이트).
2. 설정 → 내 이름 → iCloud → 드라이브: 켜기.
3. 설정 → Face ID 및 암호: 암호 설정(카드 문자가 담기므로 필수). 2단계 인증도 켜기.
4. 단축어 설정에 "알림" 항목이 없어도 정상입니다.

## 3. 카드 문자 확인 (5분)
1. 메시지 앱에서 위 4개 번호의 결제 문자가 오는지 확인(이미 확인됨). **SMS**여야 하고 앱 푸시·카톡은 안 됩니다.
2. 우리카드에서 "알림 서비스가 해지되었습니다" 문자를 받은 적이 있다면 우리카드 앱에서 승인 문자 알림이 켜져 있는지 확인하세요.
3. 메시지 앱의 알 수 없는 발신자 필터로 빠지지 않는지 확인.

## 4. Scriptable 설치 + 폴더 (5분)
1. App Store → `Scriptable` (개발자 Simon Støvring) → 받기 → 한 번 열기.
2. 설정 → 내 이름 → iCloud → 드라이브 목록에서 **Scriptable** 켜기.
3. **파일** 앱 → 둘러보기 → iCloud Drive → **Scriptable** 폴더 → 폴더 `CardLedger` 만들기 → 그 안에 폴더 `inbox` 만들기. (철자·대소문자 정확히)

## 5. 위젯 코드 넣기 (10분)
1. 최종 코드(대화창 맨 아래 코드 블록, 또는 저장소 `scriptable/CardWidget.single.js`)를 **첫 줄부터 마지막 줄(`Script.complete();`)까지 빠짐없이** 복사.
2. Scriptable → ＋ → 기존 내용 모두 지우고 붙여넣기 → 이름을 **`CardWidget`** 으로 변경.
3. ▶ 실행 → "이번 달 문자 파일이 없습니다" 표가 나오고, 닫으면 4카드가 `0`으로 나오는 위젯 미리보기가 보이면 **성공**.
   - 빨간 오류(`Can't find variable …`)가 나오면 복사가 잘렸거나 옛 코드입니다 → 전체 삭제 후 다시 붙여넣기.
4. 이때 `CardLedger` 안에 빈 `log.txt`가 자동으로 생깁니다(그냥 두세요).

### 5-1. 코드를 붙여넣을 때 주의 (실제로 겪은 오류)
- **번역 기능을 끄고** 복사·붙여넣기 하세요. 번역기가 코드 속 영어 변수 `best`를 한글 `최고`로 바꿔 놓으면 `오류: Can't find variable: 최고`가 납니다(82번째 줄 `return isNaN(best) …`).
- 붙여넣은 뒤에는 직접 고치지 않습니다. 키보드는 영문으로 두세요(한글 입력기가 글자를 끼워 넣을 수 있음).
- **원본과 같은지 폰에서 검사**: Scriptable에서 새 스크립트 `CardCheck`를 만들고 저장소의 `scriptable/CardCheck.js` 전체를 붙여넣어 ▶ 실행합니다. `원본과 완전히 같음 ✅`이 나오면 정상, `다른 구간: 81~100줄`처럼 나오면 그 구간을 원본과 비교하세요(읽기만 하고 수정하지 않습니다).
- 오류가 나면 빨간 글씨 끝에 `(줄 N:M)`이 함께 표시됩니다. 그 줄을 열어 따옴표·`//` 주석 밖의 한글 단어를 지우세요.

## 6. 자동화 만들기 (15분) — 사용자 폰 화면 기준

완성되면 위에서 아래로 카드가 이렇게 4개 보입니다.
```
[입력 없음에서 모두 받기]                         ← 기본 카드 (그대로)
[다음 조건에 맞는 메시지를 수신할 때]              ← 보낸 사람 4명, 자동화 켜짐 / 실행 전에 확인 꺼짐
[콘텐츠에서 텍스트 가져오기]
[텍스트 을(를) [inbox] 에 저장]                   ← 하위 경로 = / + 현재 날짜 + .txt
```

### 6-1. 메시지 수신 카드
1. 단축어 앱 → 맨 아래 **자동화** 탭 → ＋ → **메시지**. ("단축어 없음"이 보이면 단축어 탭입니다.)
2. **「보낸 사람 다음과 같음」** 에서 파란 `보낸 사람`(비울 수 없음) 뒤에 **4명**을 추가: 우리카드(`+82 1588-9955`), BC바로(`+82 1588-4000`), 현대카드(`+82 1577-6200`), 신한카드(`+82 1544-7200`). 연락처가 있으면 선택하고, 없으면 번호를 직접 입력해서 선택. 선택 안 되면 메시지 앱의 그 문자방 번호 → 정보 → 연락처 만들기 후 선택. **연락처에 저장된 번호가 위 번호와 같아야 합니다.**
3. **「메시지 포함 …」 줄은 지웁니다**(⊖). 현대·신한 취소 문자에는 "승인" 글자가 없습니다.
4. 카드 오른쪽 **⌄**를 눌러 펼쳐서 **`자동화` 켜짐 · `실행 전에 확인` 꺼짐** 으로 둡니다(= 즉시 실행).

### 6-2. 텍스트 꺼내기
5. 화면 아래 **검색창**에 `입력에서 텍스트` → **입력에서 텍스트 가져오기**를 추가. 카드가 `단축어 입력 에서 텍스트 가져오기` 로 보입니다.
6. 파란 칩 **`단축어 입력`** 을 눌러 창이 열리면 "받기" 목록에서 **`콘텐츠`** 를 선택(체크 이동) → 창을 아래로 쓸어 닫기. 카드가 `콘텐츠 에서 텍스트 가져오기` 로 바뀝니다. (`유형`은 건드리지 않음)
   - ⚠︎ 맨 위 카드 칩(`입력 없음`·`모두`)과 `지우기` 버튼은 건드리지 마세요(받기 종류가 전부 켜진 `모두`여야 합니다).

### 6-3. 파일 저장 (핵심)
7. 검색창에 `파일 저장` → **파일 저장**을 추가합니다. **반드시 `콘텐츠에서 텍스트 가져오기` 카드 아래**에 있어야 하고, 카드가 `[텍스트] 을(를) [폴더] 에 저장` 으로 보여야 합니다(입력 칩이 `텍스트`).
   - 순서가 뒤바뀌었거나(저장 카드가 위) 입력 칩이 `단축어 입력`이면: 저장 카드를 X로 지우고 `파일 저장`을 다시 추가하세요(새 카드는 맨 아래에 붙고 입력이 자동으로 `텍스트`가 됩니다). 또는 텍스트 카드를 길게 눌러 저장 카드 위로 끌어올린 뒤, 저장 카드의 입력 칩을 눌러 변수 목록에서 `텍스트`를 고릅니다.
   - 입력 칩이 흐린 `파일`이면 누르지 마세요(파일 선택 창이 열리니 X로 닫기).
8. 카드 오른쪽 **⌄**를 눌러 펼쳐서 **`어디에 저장할지 묻기`: 끄기**, **`파일이 있는 경우 덮어쓰기`: 끄기**.
9. 저장 폴더 칩(`Shortcuts` 등)을 눌러 **`iCloud Drive → Scriptable → CardLedger → inbox`** 를 선택합니다 → 칩이 `inbox`로 바뀝니다. (폴더를 못 고르고 `Shortcuts` 그대로면 7장 (나)로 처리)
10. **`하위 경로`** 칸에 파일 이름을 만듭니다(문자마다 달라야 덮어쓰기·누락이 없음):
    1. `/` 입력
    2. 키보드 위 막대에서 **`현재 날짜`** 선택
    3. 들어간 **`현재 날짜` 칩을 눌러** 창에서: `받기`는 **날짜**, **`날짜 포맷`은 `중간`**, **`시간 포맷`은 `길게`**. 창 맨 아래 `예:`에 **초**가 나오는지 확인하세요(같은 분에 승인과 취소가 오므로 초가 꼭 필요). `길게`에 초가 없으면 `전체`를 고릅니다. 콜론(:)이 없는 형식이 안전합니다.
    4. 오른쪽 위 **`반환하기`**(키보드 아이콘)로 입력 상태로 돌아와 칩 뒤에 **`.txt`** 를 입력
    → 결과: `/` `[현재 날짜]` `.txt`  (파일 이름 예: `2026. 10. 8. 오전 11시 3분 12초 GMT+9.txt`)
    - 키보드 위의 `변수 선택`은 누르지 않아도 됩니다(눌렀다면 X로 닫기).
11. 키보드 ✓로 입력을 끝내고, 왼쪽 위 **<** 로 나가면 저장됩니다. 이름은 `카드문자`. **▶(재생)는 누르지 마세요.**

## 7. 테스트 (10분)
1. 소액 결제(또는 승인 후 취소)를 합니다.
2. **파일 앱**에서 새 파일(`20261008_131014`처럼 날짜·시간 이름, 확장자는 없을 수도 있음)이 어디에 생겼는지 확인:
   - **(가) `iCloud Drive/Scriptable/CardLedger/inbox`** → 바로 3번으로
   - **(나) `iCloud Drive/Shortcuts` 폴더** → Scriptable 앱 → **설정(톱니바퀴) → File Bookmarks → ＋** → 그 폴더(iCloud Drive/Shortcuts)를 고르고 이름을 정확히 **`ShortcutsFolder`** 로 저장 → 3번으로
   - **(다) 어디에도 없음 / 저장 위치를 계속 물음** → 아래 "다른 방식" 참고
3. 파일을 열어 **카드 문자 원문**이 보이는지 확인.
4. Scriptable → `CardWidget` → ▶ → **진단표**: `OK 우리다모아 +9,900원` / `OK … −9,900원`(취소)처럼 나오면 정상. `카드 못 찾음`·`카드 모호`·`금액 못 찾음`이 있으면 그 줄을 캡처해 보내 주세요.
5. 표를 닫으면 위젯 미리보기에 합계가 반영되고, 승인 후 취소하면 다시 0으로 돌아옵니다.

**다른 방식 (다)**: `파일 저장`이 안 될 때만. 6-3의 `파일 저장` 카드를 X로 지우고 `텍스트 파일에 추가`(Dropbox 아닌 것)를 넣습니다. 텍스트는 앞 카드 결과, 파일은 칩을 눌러 `iCloud Drive → Scriptable → CardLedger → log.txt` 선택. 위젯이 `log.txt`를 읽습니다(연도는 순서로 복원).

## 7-2. 자동화가 동작한 뒤 해야 할 일 (완성 체크리스트)
저장이 확인됐다면 아래 순서로 마무리합니다.
1. **4개 카드 모두 확인**: 카드마다 승인(또는 취소) 문자가 한 번씩 와서 inbox에 파일이 생겼는지 봅니다(현대·BC바로·우리·신한). 한 카드라도 파일이 안 생기면 그 카드의 보낸 번호만 따로 확인하세요(연락처 번호, `+82 …` 직접 추가).
2. **위젯 코드 최신 여부**: Scriptable `CardWidget`이 최신 코드인지 확인(맨 아래 `Script.complete();`, 위에 `bodyDateIso`·`logItems`가 있으면 최신). 아니면 통째로 다시 붙여넣기.
3. **진단표 확인**: Scriptable에서 `CardWidget` ▶ → 승인은 `OK 카드 +금액`, 취소는 `OK 카드 −금액`으로 나오고 같은 결제의 승인·취소는 합계가 0으로 돌아오는지 봅니다. `카드 못 찾음`·`금액 못 찾음`이 있으면 그 줄 캡처.
4. **위젯 붙이기**: 홈 화면 길게 → ＋ → Scriptable → 가운데 크기 → 위젯 편집 → Script `CardWidget`. (잠금화면에는 올리지 않기)
5. **시작 잔액(선택)**: 오늘까지 쓴 금액이 위젯에 빠져 있으면 9번대로 `adjust.json`에 한 번만 넣기(카드사 앱 "이번 달 이용금액" − 위젯 값).
6. **테스트로 만든 파일 정리(선택)**: 취소로 순 0원이 된 테스트 파일은 그대로 둬도 합계에 영향이 없습니다. 임시 단축어(`test.txt`용)는 지워도 됩니다.
7. **매월 1~2회**: 25일경 카드사 앱 실적과 위젯을 대조하고, 위젯이 이상하면 탭해서 앱 화면을 확인합니다.

## 8. 홈 화면 위젯 (3분)

## 14. 실적 퀘스트 (CardQuest) — 경험치 바 + 동물 캐릭터 (선택, 기존 위젯과 별개)
카드 실적을 RPG 경험치 바처럼 보여줍니다. 기존 `CardWidget`은 그대로 두고, **새 스크립트 `CardQuest`**를 추가합니다. 데이터(inbox 문자 파일)와 계산은 카드 위젯과 **같은 코드**를 쓰므로 숫자가 어긋나지 않습니다.

| 카드 | 캐릭터 | 레벨 | 바 |
|---|---|---|---|
| BC바로 | 🦊 | 30만 미만 Lv0 / 30만 이상 Lv1 / 60만 이상 Lv2(MAX) | 30만을 달성하면 바가 0에서 다시 시작해 30~60만 구간을 채움 |
| 현대ED3 | 🐻 | 40만 이상 Lv1(CLEAR) | 40만까지 |
| 신한 | 🐱 | 0원보다 크면 ACTIVE | 바 없음, "활동 중" + 금액 |
| 우리다모아 | 🐰 | 10만 이상 Lv1(CLEAR) | 10만까지 |

- 막대 색: 33% 미만 빨강, 67% 미만 주황, 그 이상 노랑, 클리어/MAX 초록. 취소로 합계가 음수가 되면 0으로 표시합니다.
- 맨 위 `파티 2/5`는 달성한 구간 수(BC 2 + 현대 1 + 우리 1 + 신한 1 = 5 중)입니다.
- 맨 아래 한 줄: 가장 가까운 다음 목표(예: `다음: 현대ED3 40만까지 32만`).

### 14-1. 설치 (5분)
1. 저장소의 `scriptable/CardQuest.single.js` **전체**를 복사합니다(번역 끄기, 영문 키보드).
2. Scriptable → ＋ → 붙여넣기 → 이름을 **`CardQuest`** 로 바꿉니다.
3. ▶ 실행 → **전체 화면 퀘스트 화면**이 열립니다(캐릭터·바가 차오름). 닫으면 위젯 미리보기가 나옵니다.
4. 원본과 같은지 검사: 새 스크립트 `CardQuestCheck`에 `scriptable/CardQuestCheck.js`를 붙여넣고 ▶ → `원본과 완전히 같음 ✅`.
5. 홈 화면: 길게 → ＋ → Scriptable → **가운데 크기** → 위젯 편집 → Script `CardQuest`. 위젯을 탭하면 전체 화면이 열립니다.

### 14-2. 전체 화면(탭) 기능
- 막대가 0에서 현재 값까지 차오르는 애니메이션, 캐릭터 크게 표시.
- **레벨업 연출**: 지난번 본 것보다 레벨이 올랐을 때 한 번만 🎉. 기록은 `CardLedger/quest-state.json`에 저장되고 매달 새로 시작합니다. 처음 실행할 때는 연출이 없습니다.
- **숨겨진 미리보기(개발자용)**: 맨 위 제목 `실적 퀘스트`를 **7번 탭**하면 슬라이더가 나타나 금액을 움직여 화면·레벨업 효과만 시험할 수 있습니다. 실제 합계와 저장 파일은 바뀌지 않습니다.

### 14-3. 크기·이미지
- 글자 크기: 코드의 `const FS = 13;` 숫자만 바꿉니다(11~14 권장).
- 이모지 대신 이미지는 아직 지원하지 않습니다(필요하면 요청).
- 막대 그림을 그리지 못하는 환경이면 자동으로 글자 막대(`▰▰▱▱`)로 바뀝니다.

### 14-4. 문제 해결
| 증상 | 원인·해결 |
|---|---|
| `오류: … (줄 N:M)` | 붙여넣기 중 글자가 바뀜 → `CardQuestCheck`로 어느 구간인지 확인, 전체 삭제 후 다시 붙여넣기 |
| 위젯 숫자가 안 바뀜 | 홈 위젯은 iOS가 갱신 → 위젯을 탭해 전체 화면에서 확인 |
| 이모지가 어긋남 | 아이폰 글꼴 차이 → `FS`를 1~2 조절 |
| 레벨업 연출이 안 나옴 | 이미 본 레벨이면 정상. 다시 보려면 `CardLedger/quest-state.json`을 삭제(첫 실행처럼 연출 없음) |
