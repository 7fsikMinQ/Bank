# 카드 실적 위젯 — 초보자 따라하기 가이드 (아이폰 16 Pro 전용)

> 이 가이드는 **아이폰만 있고 아무것도 모르는 상태**에서 시작합니다. 컴퓨터는 필요 없습니다.
> 총 소요시간: 처음 한 번 약 **60~90분**. 이후 사용은 위젯 보기만.
> ✅ **지금 4번(폴더 만들기)까지 하셨다면 → 바로 §5(코드 넣기)부터 이어서 하세요.** 코드가 규칙 변경으로 **새로 바뀌었으니** §5에서 최신 코드를 다시 복사해야 합니다(이미 붙여넣었다면 전체 삭제 후 다시 붙여넣기).
> ⚠︎ 아이폰 화면 글자(버튼 이름)는 iOS 버전에 따라 조금 다를 수 있습니다. 같은 뜻의 버튼을 찾으시면 됩니다. 이 환경에서는 실제 아이폰으로 눌러볼 수 없었으므로, **막히면 그 화면을 캡처해서 보내주세요.**

## 0. 먼저 이해하기 (2분)

우리가 만들 것: 카드를 쓰면 카드사가 **문자**를 보냅니다 → 아이폰이 그 문자를 **파일로 저장**합니다 → **위젯**이 파일을 읽어 "이번 달 카드별 사용액 / 다음 혜택 구간"을 계산해 보여줍니다.

| 도구 | 역할 | 비용 |
|---|---|---|
| 메시지 앱 (기본) | 카드 문자 수신 | 무료 |
| 단축어 앱 (기본) | 문자 오면 자동으로 파일 저장 | 무료 |
| iCloud Drive (기본) | 파일 저장 장소 | 무료 5GB |
| **Scriptable** (App Store) | 위젯 그리기 + 계산 | 무료 |
| 카드사 "승인 문자" 서비스 | 문자를 받기 위한 것 | 카드사별 무료~월 수백 원 |

**서버 없음 · 외부 전송 없음 · 계정 로그인 없음.** 카드 문자 내용은 내 아이폰과 내 iCloud 안에서만 움직입니다.

## 1. 내 아이폰 점검 (5분)

1. **설정** 앱 → **일반** → **정보** → "iOS 버전"을 봅니다. **iOS 18 이상**이면 충분합니다(16 Pro는 iOS 26/27까지 가능). 낮다면 **설정 → 일반 → 소프트웨어 업데이트**.
2. **설정 → 맨 위 내 이름(Apple 계정) → iCloud → 드라이브**: 켜져 있어야 합니다. 이름이 안 보이면 Apple 계정 로그인부터.
3. 같은 화면에서 저장 공간이 꽉 차 있지 않은지 확인(이 작업은 몇 KB만 씁니다).
4. **설정 → 알림 → 단축어**: **알림 허용** 켜기. (자동으로 실행될 때 알림 권한이 필요하다는 정보가 있습니다.)
5. **설정 → Face ID 및 암호**: 암호가 설정되어 있는지 확인. 카드 문자가 담기므로 필수.
6. **설정 → Apple 계정 → 암호 및 보안 → 2단계 인증**: 켜져 있는지 확인(iCloud 보호).

## 2. 카드 4장의 "승인 문자" 준비 (가장 중요, 15~30분)

이게 안 되면 아무것도 안 됩니다. **카드사 앱 푸시(앱 알림)는 이 방식에서 쓸 수 없고, 반드시 '문자(SMS)'** 여야 합니다. 카톡 알림톡도 불가.

1. **메시지 앱**을 열어 지난 카드 결제 때 온 문자가 있는지 검색창에 "승인"을 입력해 봅니다.
2. 4장(BC 바로 K-패스, 네이버 현대카드 ED3, 신한, 우리다모아) 모두 문자가 오고 있으면 3번으로.
3. 안 오는 카드는 카드사 **앱 또는 고객센터**에서 "결제(승인) 문자 알림 서비스"를 신청합니다. 카드사마다 신청 위치·요금이 다르니 **신청 화면의 요금 안내를 꼭 읽고** 진행하세요(무료~월 수백 원 정도로 알려져 있으나 정확한 금액은 직접 확인 필요).
   - BC카드 고객센터 1588-4000(검색에서 확인된 번호). 나머지는 각 카드 뒷면 번호.
   - 앱 푸시 알림만 켜는 것으로 끝내면 안 됩니다(문자가 아님).
4. **소액 결제**(편의점 1,000원 등)를 해서 문자가 오는지 확인합니다.
5. 문자 형식을 **확인해서 메모/캡처**합니다 (§12에서 저에게 보내줄 자료):
   - 카드 이름이 문자 맨 앞에 어떻게 나오는지 (예: `[신한카드]`, `현대카드`)
   - **BC 바로(신용)** 문자에 "비씨"와 "신용"이 **둘 다** 나오는지, **우리다모아** 문자가 "우리"로 나오는지 또는 "비씨 체크"로 나오는지
   - 금액이 "12,000원"처럼 나오는지
   - "누적" 금액이 같이 오는지
   - 취소 문자에 "취소"라는 글자가 있는지
6. 메시지 앱 **필터**가 켜져 있으면 카드 문자가 "알 수 없는 발신자" 쪽으로 빠질 수 있습니다. **설정 → 앱 → 메시지 → 알 수 없는 발신자 및 스팸**의 필터를 확인하고, 카드 문자가 **받은 메시지(일반)** 에 오는지 봅니다. 숨겨졌다면 해당 번호를 연락처에 저장하세요.

> 🔒 **보안**: 문자 캡처를 저에게 보낼 때 카드번호 일부·이름·승인번호는 **가리고** 금액·가맹점·날짜 형태만 보여주세요.

## 4. 저장 폴더 만들기 (3분)

1. **파일** 앱 → 아래 **둘러보기** → **iCloud Drive** → **Scriptable** 폴더를 엽니다 (3번을 했다면 보입니다).
2. 오른쪽 위 폴더 모양(＋) 버튼 → 이름 `CardLedger` 로 새 폴더.
3. `CardLedger` 안으로 들어가 다시 새 폴더 → 이름 `inbox`.
4. 결과: `iCloud Drive/Scriptable/CardLedger/inbox` (**철자·대소문자 정확히**).

## 5. 위젯 코드 넣기 (10분)

코드는 이 저장소의 **`scriptable/CardWidget.single.js`** 파일(또는 `docs/카드실적-위젯-설계서.md` 맨 아래 부록)에 있습니다.

1. Claude 앱에서 위 파일/부록을 열고 코드 전체를 **길게 눌러 전체 선택 → 복사**합니다. 맨 첫 줄(`// 카드 실적 집계 코어…`)부터 마지막 줄(`Script.complete();`)까지 **빠짐없이**.
2. **Scriptable** 앱 → 오른쪽 위 **＋** → 새 스크립트가 열리면 기존 내용을 모두 지우고 **붙여넣기**.
3. 맨 위 스크립트 이름(기본 "Untitled Script")을 눌러 **`CardWidget`** 으로 변경 (대소문자 정확히).
4. 오른쪽 아래 **▶(재생)** 버튼을 누릅니다.
   - "이번 달 문자 파일이 없습니다" 같은 표가 나오고, 닫으면 4카드가 `0/…만`으로 나오는 위젯 미리보기가 보이면 **성공**입니다.
   - 빨간 "오류:" 문구가 나오면 → 대부분 4번 폴더 이름 철자 문제 → 다시 확인. 그래도 안 되면 화면 캡처.

## 6. 자동화 만들기 — 핵심 (카드별 1개씩, 총 4개, 25분)

한 카드를 완성한 뒤 **복제**해서 나머지를 만듭니다. 먼저 **신한** 예시.

### 6-0-1. 카드별 자동화 설정표 (이 표대로 4개 만드세요)

카드 구분은 **문자 본문 앞부분**으로 합니다. 규칙(코드에 들어 있음):

| 카드 | 문자에 있어야 하는 글자 |
|---|---|
| **BC 바로 K-패스** | **"비씨"(또는 BC)와 "신용" 둘 다** (순서·띄어쓰기 무관) |
| **우리다모아** | **"우리"** 가 있거나 **"비씨 체크"** (또는 BC 체크) |
| 네이버 현대카드 ED3 | "현대카드" |
| 신한카드 | "신한" |

| # | 자동화 이름 | **메시지에 포함**(트리거 문구) | ④ 텍스트 **1줄 태그**(직접 타이핑) |
|---|---|---|---|
| 1 | 카드문자-비씨 | `비씨` | `비씨` |
| 2 | 카드문자-우리 | `우리` | `우리카드` |
| 3 | 카드문자-현대 | `현대카드` | `현대카드` |
| 4 | 카드문자-신한 | `신한` | `신한` |

- **1번(`비씨`)이 BC 바로(신용)와 우리다모아(비씨 체크) 문자를 둘 다 받습니다.** 둘을 가르는 일은 코드가 문자 본문의 "신용/체크"로 합니다. 그래서 1번 태그는 반드시 `비씨`처럼 **애매하게** 둡니다(`BC바로`나 `우리`로 적지 마세요).
- 문자에 "BC"가 영문으로 오면 `비씨` 대신 `BC`로 트리거를 거세요(§6-0에서 실제 문자의 글자를 확인).
- 같은 문자가 두 자동화(예: 1번과 2번)에 동시에 걸려 파일이 2개 생겨도 **자동으로 1건**으로 계산됩니다.
- 신한·현대 문자에 가맹점 글자("우리약국" 등)가 있어 다른 자동화가 같이 실행돼도 **본문 앞부분이 우선**이라 안전합니다.
- 진단표(§7)에 `카드 못 찾음`이 뜨면: BC 문자에 "신용"/"체크" 중 하나가 빠졌거나 "비씨" 표기가 다른 것입니다 → 그 문자 캡처를 보내주세요.

### 6-0. 먼저 카드 문자에서 "고정 문구" 찾기
메시지 앱에서 그 카드의 결제 문자를 열어 **항상 들어있는 짧은 문구**를 찾습니다. 예: `신한카드`. (취소 문자에도 같은 문구가 들어있어야 합니다.) 이 문구를 아래 6-2에서 씁니다. **다른 사람이 보낼 일 없는 구체적인 문구**로(예: 위 표의 문구. 너무 흔한 한 글자는 피하세요).

### 6-1. 새 자동화
1. **단축어** 앱 → 아래 **자동화** 탭 → 오른쪽 위 **＋** → **새로운 자동화**(개인 자동화) → **메시지**.
2. **보낸 사람**은 비워 둡니다(연락처에 없는 번호는 고를 수 없으므로).
3. **메시지에 포함**에 6-0의 문구를 입력(예: `신한카드`) → **다음**.
4. 맨 아래 **실행 방식**: **즉시 실행** 선택 (※ 아래 §10-①). **알림 받기**는 켜 둬도 됩니다.

### 6-2. 동작 추가 (위에서 아래 순서 그대로)
**동작 추가** 버튼 → 검색창에 이름을 쳐서 하나씩 추가:

| 순서 | 동작 | 설정 |
|---|---|---|
| ① | **현재 날짜** | 그대로 |
| ② | **날짜 포맷** | 날짜: ①의 결과 / 날짜 포맷: **사용자 지정** → `yyyyMMdd-HHmmss` |
| ③ | **난수** | 최소 1000, 최대 9999 |
| ④ | **텍스트** | 아래 "④ 텍스트 만들기" 참고 |
| ⑤ | **파일 저장** | 아래 "⑤ 파일 저장" 참고 |

**④ 텍스트 만들기** — 텍스트 칸을 눌러 **3줄**을 이렇게 씁니다 (줄바꿈은 키보드 '줄바꿈' 키):
```
1줄: 비씨            ← 위 §6-0-1 표의 "태그"를 직접 타이핑 (비씨 / 우리카드 / 현대카드 / 신한)
2줄: (변수) 현재 날짜 ← 키보드 위 변수 목록에서 "현재 날짜" 선택 → 그 변수를 눌러 날짜 형식 "ISO 8601"
3줄: (변수) 단축어 입력 ← 키보드 위 변수 목록에서 "단축어 입력" 선택
```
- 1줄은 **태그**입니다(§6-0-1 표). 문자 본문에 카드 표시가 있으면 본문이 우선이고, 본문에 표시가 없을 때만 태그가 쓰입니다.
- 2줄이 어렵거나 이상하면 걱정 마세요 — **파일 이름의 날짜로 자동 복구**됩니다.

**⑤ 파일 저장**
- **서비스**: iCloud Drive
- **저장 위치 묻기**: **끄기** (꺼야 자동으로 저장됩니다)
- **대상 경로**: 폴더 선택에서 `Scriptable → CardLedger → inbox`
- **파일 이름**: ②의 날짜 변수 + `-` + ③의 난수 변수 + `.txt` (예: `[포맷된 날짜]-[난수].txt`)
- **덮어쓰기**: 켜 둬도 되고 꺼도 됩니다(이름이 매번 달라서 무관)

저장하고 이름을 `카드문자-신한` 처럼 붙입니다.

### 6-3. 나머지 카드
**자동화 목록에서 방금 만든 것을 길게 눌러 복제** 가능한 버전이면 복제, 아니면 같은 방법으로 새로 만들되 ① 6-1의 문구 ② ④의 1줄 태그만 바꿉니다.

## 7. 첫 테스트 (10분)

1. 소액 결제(또는 방금 한 결제의 새 문자)를 합니다.
2. 몇 초 뒤 **파일 앱 → iCloud Drive → Scriptable → CardLedger → inbox** 에 `20261007-123456-1234.txt` 같은 파일이 생겼는지 봅니다.
   - **안 생겼다면**: §10 표.
3. 파일을 눌러 열어 봅니다. **1줄 카드태그 / 2줄 날짜 / 3줄~ 문자 본문** 이 보여야 합니다. 3줄 이후가 비었거나 이상하면 **캡처해서 보내주세요**(단축어 입력 변수를 조정해야 합니다).
4. **Scriptable → CardWidget → ▶** 를 누르면 **진단표**가 먼저 뜹니다:
   - `OK 신한 +1,000원` 처럼 나오면 정상.
   - `카드 못 찾음`/`금액 못 찾음`/`카드 모호` → 문자 형식 문제. 그 줄이 보이게 **캡처해서 보내주세요**(§12).
5. 표를 닫으면 위젯 미리보기에서 금액이 반영됐는지 확인.
6. 취소도 한 번 테스트: 같은 카드로 결제 후 **취소** → 진단표에 `−` 금액이 생기고 합계가 줄어야 합니다.

## 8. 홈 화면에 위젯 붙이기 (3분)

1. 홈 화면 빈 곳을 **길게 누릅니다** → 왼쪽 위 **＋**.
2. 목록에서 **Scriptable** 선택 → **가운데 크기(Medium)** 선택 → **위젯 추가**.
3. 방금 놓은 위젯을 **길게 누름 → 위젯 편집** → **Script**: `CardWidget` 선택.
4. 위젯을 **탭**하면 Scriptable 앱이 열려 **지금 시점의 최신 계산 결과**(진단표 → 위젯 미리보기)를 바로 보여줍니다. (홈 화면의 위젯 자체는 iOS가 정한 주기로 갱신되며 탭한다고 즉시 바뀌지는 않을 수 있습니다.)

> 🔒 이 위젯은 **홈 화면용**입니다. 잠금화면에는 올리지 마세요(금액이 잠금 상태에서 보일 수 있음).

## 9. 위젯 읽는 법과 평소 사용

```
10월 1~31일 카드실적
BC바로KPASS      35/60만      ← 지금 35만, 다음 혜택 구간 60만 (빨강: 미달, 초록: 구간 달성)
현대ED3           8/40만
신한?             1.2/30만     ← ? : 구간 금액을 아직 확정 못한 임시값
우리다모아?       0/30만
7/31일차 · 갱신 21:12      ← 이번 달 31일 중 7일째
```
- `*35/60만` : 카드사 문자의 "누적 이용액"과 내 합산이 다름 → 제외항목/누락 점검 신호(문자 누적액은 할부·현금서비스까지 포함하므로 오류가 아닐 수도 있음)
- `⚠︎2` (제목 옆): 금액을 못 읽은 문자 2건 → 앱에서 위젯 스크립트 실행해 진단표 확인
- **방금 쓴 결제가 안 보이면 위젯을 탭**해 앱에서 최신 값을 확인하세요(앱 화면은 항상 최신). 홈 화면 위젯의 자동 갱신은 iOS가 결정합니다(수 분~1시간).
- **월 계산 규칙**: 한 달은 **한국시간 1일 0시 ~ 말일 24시**입니다. 2월 28일(윤년 29일), 4·6·9·11월 30일, 나머지 31일을 자동으로 반영하고 12월→1월도 자동입니다. **매달 1일 0시에 자동으로 0부터 새로 시작**(할 일 없음). 위젯 제목 `10월 1~31일`과 하단 `7/31일차`로 확인할 수 있습니다.
- 전월 결제를 이번 달에 **취소**하면 이번 달에서 차감됩니다(카드사는 원래 결제한 달에서 차감). 25일 공식 실적과 차이가 나면 `adjust.json`으로 맞추세요.
- **25일경**: 카드사 앱의 공식 실적과 한 번 대조하세요(제외항목 차이 확인).
- 누락 문자 보정: `iCloud Drive/Scriptable/CardLedger/adjust.json` 파일(메모 앱 내용을 .json으로 저장해도 됨)에 `{"sh": 12000}` 처럼 적습니다. 카드 id: bc(BC) · hd(현대) · sh(신한) · wr(우리), 값은 원 단위 숫자(음수 가능, ±1천만 원 이내). 이 값은 **매달 계속 더해지므로** 새 달이 되면 지우거나 고치세요.

## 10. 막혔을 때 (증상 → 원인 → 해결)

| 증상 | 가능한 원인 | 해결 |
|---|---|---|
| ① "즉시 실행"이 안 보임/선택 불가, 또는 문자 올 때마다 "실행할까요?" 알림이 뜸 | 메시지 트리거는 일부 문서에서 '항상 확인'으로 안내됨. iOS 15.4 이후 모든 자동화가 즉시 실행 가능하다는 자료도 있어 **실제 기기에서 확인 필요** | (a) 설정 > 알림 > 단축어 허용 확인 (b) 그래도 막히면 **문자 알림의 '실행' 탭 1회**로 저장되게 사용 (c) 그것도 불편하면 §11 대안 |
| inbox에 파일이 안 생김 | 문구 불일치 / 필터로 숨김 / 저장 위치 묻기 켜짐 / 알림 꺼짐 | 6-0 문구 재확인, 필터 확인, 6-2⑤ 설정 재확인 |
| 파일은 있는데 3줄 이후가 비어 있음 | "단축어 입력"이 본문으로 안 넘어옴 | 캡처 보내주세요(동작 보강) |
| 진단표 "카드 못 찾음" | BC 문자에 "비씨/신용/체크" 중 빠진 글자가 있음, 또는 카드명이 다른 표기 | 문자 캡처 보내주세요(규칙 보정). 1줄 태그는 §6-0-1 표대로 |
| 진단표 "카드 모호" | 문자 머리말에 두 카드 글자가 함께 있음 | 문자 캡처 보내주세요 |
| "금액 못 찾음" | 금액이 "원" 없이 표기/해외결제 | 문자 캡처 보내주세요 |
| 앱에서 "Can't find variable: …" 류 빨간 오류 | 코드 일부만 복사/예전 코드 | 스크립트 전체 삭제 후 **최신 코드 전체**를 다시 붙여넣기. 그래도 나면 오류 문구 캡처 |
| 위젯 "오류: inbox 폴더 없음" | 폴더 경로·철자 | §4 재확인 (iCloud Drive/Scriptable/CardLedger/inbox) |
| 파일이 늦게 보임 | iCloud 동기화 지연 | 잠시 후 위젯 탭(앱에서 확인), 와이파이 확인 |
| 월이 바뀌었는데 지난달 숫자가 보임 | 홈 화면 위젯이 아직 갱신 전 | 위젯 탭 → 앱 화면은 이미 새 달 기준(홈 위젯은 iOS 갱신을 기다림) |
| 1일 새벽에 온 문자가 전달에 들어간 것 같음 | 문자 수신 시각이 전날 23:59대 | 진단표에서 문자 시각 확인(한국시간 기준 0시를 넘겨 수신된 문자만 새 달로 계산됨) |
| 금액이 실제와 다름 | 실적 제외 항목/누락 문자 | `*`·진단표 확인, `adjust.json` 보정, 25일 공식 실적 대조 |

## 11. 대안 (자동화가 정 안 될 때)

1. 문자 알림 탭으로 실행하는 반자동(§10-①-b)
2. 메시지에서 문자를 **길게 눌러 복사** → 같은 저장 단축어를 **수동 실행**
3. 특정 카드만 문자가 안 오면 그 카드만 수동 입력
4. 카드사 앱의 공식 "이번 달 실적" 화면 + 25일 점검(가장 단순)

## 12. 저에게 보내줄 것 (정확도를 확정하는 마지막 단계)

카드 4장 각각: ① **승인 문자 1개** ② **취소 문자 1개** ③ (있으면) 해외결제·할부 문자. + 위젯 진단표 캡처.
금액·가맹점·날짜 형식만 보이게, 카드번호·이름·승인번호는 가려서. 그리고 **신한·우리다모아의 실적 구간 금액**(카드사 앱 혜택 화면 기준).
→ 받으면 카드 판별 규칙·제외 항목·구간 금액을 확정해 최종판을 드립니다.

## 14. 검토 기록

- **분석 5회**: ① 앱 대안(더쎈 종료·토스·뱅샐·네이버페이) ② SMS 입력 경로(iOS는 SMS 읽기 API 없음) ③ 단축어 트리거 제약 ④ 저장·동시성 ⑤ 위젯 갱신·보안
- **검토 10회 / 최종 15회 점검**(자동 테스트로 재현 가능한 항목은 `npm test`): 취소·부분취소·월경계·오분류·잔액오인식·중복·날짜복구·보정·구간·퍼즈 300회·네트워크 코드 부재·위젯 실행 모의(위젯 모드/앱 모드)
- **월 규칙 라운드**: 1일 0시~말일 23:59:59(KST), 월별 일수·윤년·연도 넘김, 시간대 독립, 120개월 경계 전수 테스트(4개 시간대), 위젯 월 범위/일차 표시, 파일 읽기 범위(이번 달+전달), 문자열 시각 비교 → 실제 시각 비교
- **이번 라운드 변경**: 카드 태그(1줄) 우선 판별, 중복 60초 창, 파일/입력 상한, 보정값 검증, 진단표(앱 실행 시), 보안 정적 검사 테스트
- **확인하지 못한 것(정직)**: 단축어 메시지 트리거의 "즉시 실행" 가능 여부(자료 상충), "단축어 입력"이 본문으로 넘어오는 정확한 형태, 4개 카드 실제 문자 형식, 신한·우리 구간, 문자 서비스 요금. 이 환경은 아이폰·카드사·Apple 지원 사이트에 접근할 수 없어 **폰에서 §7 테스트로만 확정**됩니다.
