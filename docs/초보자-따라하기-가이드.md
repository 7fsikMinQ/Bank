# 카드 실적 위젯 — 최종 따라하기 가이드 (아이폰 16 Pro · 처음부터 끝까지)

> 컴퓨터 필요 없음. **처음 한 번 약 40~60분**, 이후엔 위젯만 보면 됩니다.
> 화면 글자는 iOS 버전에 따라 조금 다를 수 있습니다. 같은 뜻의 버튼을 찾으세요. 막히면 **그 화면을 캡처**해서 보내 주세요(카드번호·이름은 가리고).

---

## 0. 최종 확정 사항 (사용자 폰에서 확인된 값)

| 카드 | 보낸 번호 | 승인 문자 | 취소 문자 | 위젯 목표 |
|---|---|---|---|---|
| **BC 바로** | `1588-4000` | `BC바로(…) 승인` | `BC바로(…)승인취소` | **30만 → 60만** (2구간) |
| **네이버 현대 ED3** | `1577-6200` | `현대 네이버 승인` | `현대 네이버 취소` | **40만** |
| **신한카드** | `+82 1544-7200` | `신한카드(…)승인` | `신한카드(…)취소` | **목표 없음 — 0원만 아니면 달성** |
| **우리다모아** | `+82 1588-9955` | `우리카드(…)체크승인` / `우리카드(…) 승인` (또는 `BC체크…`) | `우리카드(…)승인취소` | **10만** |

- 우리다모아는 **두 가지 표기**("우리카드…"와 "BC 체크…")를 모두 우리 한 카드로 합산합니다.
- **월 범위: 매월 1일 0시 ~ 말일 23:59:59** (28/29/30/31일·윤년 자동). **1일이 되면 그달 합계는 0부터 새로 시작**하고, 지난달 문자는 합계에서 빠집니다.
- 어느 달에 넣을지는 **문자 본문의 거래 일시**(예: `10/31 23:59`)로 정합니다 → 자동화가 늦게 실행돼 저장이 다음 달로 넘어가도 **결제한 달**에 정확히 들어갑니다(12/31 23:50 결제가 1/1에 저장돼도 12월).
- 문자에 있는 **`총누적`/`누적` 금액은 그달 누적이 아니므로 계산에 쓰지 않습니다.** 위젯은 그 달 1일부터 말일까지의 승인(+)과 취소(−) 금액만 더합니다.
- 취소("취소" 글자 포함)는 **−금액**. 부분취소도 문자에 적힌 금액만큼 차감.
- **달러 결제**: 문자에 "원" 금액이 없고 `22.00 달러`처럼 오면 **1달러 = 1,320원 고정**으로 환산(22달러 → 29,040원).
- 서버·DB·로그인·인터넷 전송 **없음**. 문자는 내 아이폰과 내 iCloud 안에서만 움직입니다.

### 위젯에 이렇게 보입니다
```
10월 1~31일 카드실적
BC바로KPASS      35/60만       ← 지금 35만, 다음 목표 60만 (30만은 이미 달성). 빨강=미달, 초록=달성
현대ED3           8/40만
신한              12,000원      ← 목표 없음: 0원보다 크면 초록, 0원이면 빨강
우리다모아        0.99/10만
8/31일차 · 갱신 21:12
```
`⚠︎N` (제목 옆) = 금액을 못 읽은 문자 N건(달러 외 통화 등)

## 1. 도구 (모두 무료)

| 도구 | 역할 |
|---|---|
| **메시지** 앱 (기본) | 카드 문자 수신 |
| **단축어** 앱 (기본, 보라/분홍 아이콘) | 문자가 오면 자동으로 파일로 저장 |
| **파일** 앱 + iCloud Drive (기본) | 저장 장소 |
| **Scriptable** (App Store, 개발자 Simon Støvring) | 위젯을 그리고 금액을 계산 |

> Scriptable과 단축어는 **서로 다른 앱**입니다. 둘 다 필요합니다.

## 2. 내 아이폰 점검 (5분)
1. **설정 → 일반 → 정보**: iOS 18 이상(16 Pro는 iOS 26/27 가능). 낮으면 **일반 → 소프트웨어 업데이트**.
2. **설정 → 맨 위 내 이름 → iCloud → 드라이브**: 켜져 있어야 함.
3. **설정 → Face ID 및 암호**: 암호 설정 확인(카드 문자가 담기므로 필수).
4. **설정 → 내 이름 → 암호 및 보안 → 2단계 인증**: 켜기.
5. 단축어 설정에 "알림" 항목이 없어도 **정상**입니다(앱이 아직 권한을 요청하지 않았을 뿐). 자동화를 만들 때 "알림을 보내려 합니다" 창이 뜨면 **허용**.

## 3. 카드 문자 확인 (5분)
1. **메시지** 앱에서 위 표의 4개 번호 문자방이 있고, 결제 때 문자가 오는지 확인합니다. (이미 확인된 상태: 4개 카드 모두 승인·취소 문자가 옵니다.)
2. 문자가 **앱 푸시/카톡이 아니라 SMS**인지 확인(화면 아래 입력칸에 "문자 메시지 • SMS"가 보이면 SMS).
3. 우리카드에서 예전에 "[우리카드] … 알림 서비스가 해지되었습니다"라는 문자가 왔다면, **우리카드 앱에서 결제 승인 문자 알림이 켜져 있는지** 한 번 더 확인하세요(오늘 승인 문자는 정상 수신됨).
4. 메시지 **필터**가 켜져 있으면 문자가 "알 수 없는 발신자"로 빠질 수 있습니다(설정 → 앱 → 메시지). 카드 문자는 일반 받은 메시지에 와야 합니다.

## 4. Scriptable 설치 + 폴더 (5분)
1. **App Store** → `Scriptable` → 개발자 **Simon Støvring** 확인 → **받기** → 한 번 열어 봅니다.
2. **설정 → 내 이름 → iCloud → 드라이브** 목록에서 **Scriptable**이 켜져 있는지 확인.
3. **파일** 앱 → 둘러보기 → **iCloud Drive** → **Scriptable** 폴더 열기.
4. 오른쪽 위 폴더(＋) 버튼 → 새 폴더 이름 `CardLedger`.
5. `CardLedger` 안으로 들어가 새 폴더 → 이름 `inbox`.
6. 결과: `iCloud Drive / Scriptable / CardLedger / inbox` (**철자·대소문자 정확히**).

## 5. 위젯 코드 넣기 (10분)
1. 이 가이드와 함께 드린 **최종 코드**(대화창 맨 아래 코드 블록, 또는 저장소의 `scriptable/CardWidget.single.js`)를 **길게 눌러 전체 선택 → 복사**합니다. 첫 줄(`// 카드 실적 집계 코어…`)부터 마지막 줄(`Script.complete();`)까지 **빠짐없이**.
2. **Scriptable** → 오른쪽 위 **＋** → 기존 내용 모두 지우고 **붙여넣기**.
3. 맨 위 이름(Untitled Script)을 눌러 **`CardWidget`** 으로 변경.
4. 오른쪽 아래 **▶** 실행 → "이번 달 문자 파일이 없습니다" 표가 나오고, 닫으면 4카드가 `0/…`로 나오는 위젯 미리보기가 보이면 **성공**.
   - 빨간 오류(`Can't find variable …`, `Unexpected …`)가 나오면 **복사가 중간에 잘렸거나 옛 코드**입니다 → 전체 삭제 후 처음부터 끝까지 다시 붙여넣기.
   - "inbox 폴더 없음"이면 4번 폴더 철자를 확인.

## 6. 자동화 만들기 — 핵심 (자동화 1개 · 보낸 사람 4개 · 동작 2개, 15분)

### 6-1. 자동화 시작
1. **단축어** 앱 → 맨 아래 **자동화** 탭 → 오른쪽 위 **＋** → **메시지**.
   ("단축어 없음"이 보이는 곳은 단축어 탭입니다. **자동화 탭**이어야 합니다.)
2. 편집 화면의 **「보낸 사람 다음과 같음 [보낸 사람]」** — 파란 글자 "보낸 사람"(흐린 쪽)을 누릅니다. (이 아이폰에서는 비워 둘 수 없습니다.)
3. 아래 **4개 번호를 모두** 추가합니다.

   | 카드 | 입력할 번호 |
   |---|---|
   | 우리다모아 | `+82 1588-9955` (안 되면 `1588-9955`) |
   | BC 바로 (BC 체크 포함) | `1588-4000` (연락처 "비씨카드"가 보이면 그걸 선택) |
   | 현대 ED3 | `1577-6200` (연락처 "현대카드"가 보이면 그걸 선택) |
   | 신한 | `+82 1544-7200` (안 되면 `1544-7200`) |

   - 번호를 입력하면 아래에 뜨는 번호를 눌러 선택합니다. **여러 명을 한 번에** 고를 수 있습니다.
   - 선택이 안 되면: 메시지 앱에서 그 문자방 맨 위 번호 → **정보(ⓘ) → 연락처 만들기**로 저장 후 그 연락처를 고릅니다.
   - 위쪽 "이 자동화를 활성화하려면 '보낸 사람'을(를) 구성하십시오" 문구가 사라지면 성공.
4. **「메시지 다음을 포함 승인」 줄 오른쪽 ⊖(빼기)를 눌러 지웁니다.** 현대·신한의 취소 문자에는 "승인" 글자가 없어서, 남겨 두면 취소가 누락됩니다. (이 번호들은 카드 알림만 보냅니다.)

### 6-2. 동작 2개
5. 화면 아래 **검색창**(돋보기)에 `입력에서 텍스트`를 입력 → **입력에서 텍스트 가져오기**를 누릅니다. (※ "단축어 입력"은 동작이 아니라 변수라서 이 검색창에서 `단축어`를 쳐도 안 나옵니다. 그 동작이 문자 본문을 자동으로 꺼내 주므로 변수를 고를 필요가 없습니다.)
   - 동작이 추가되면 `단축어 입력 에서 텍스트 가져오기`처럼 보입니다. 파란 칩 `단축어 입력`이 이미 들어 있으면 지우지 마세요.
   - **파란 칩 `단축어 입력`을 누르면** 창이 열립니다. "받기" 목록에서 **`콘텐츠`**(문자 본문)를 선택하고(체크가 `메시지`에서 `콘텐츠`로 이동), 창을 아래로 쓸어 닫습니다. `유형`은 건드리지 않습니다. (맨 위의 "입력 없음에서 앱 및 18개 받기" 카드는 기본 설정이니 그대로 둡니다.)
   - 저장된 파일 내용이 비어 있으면 `콘텐츠` 대신 `메시지`로 바꿔 다시 테스트합니다.
   - ⚠︎ 설정 중에는 **▶(재생)를 누르지 마세요**(문자 없이 실행되어 빈 파일이 생깁니다).
   - 이 이름이 안 보이면 `텍스트 가져오기`로 검색해 보세요. 그래도 없으면 대안: `메시지의 세부사항` 검색 → **메시지의 세부사항 가져오기** → 세부사항을 **콘텐츠**로 바꿉니다.
6. 검색창에 `파일 저장` → **파일 저장**을 누릅니다. 입력은 바로 위 동작의 결과(텍스트)가 자동으로 들어옵니다.
   - **저장 위치 묻기: 끄기**
   - **대상 경로**: iCloud Drive → Scriptable → CardLedger → **inbox**
   - **덮어쓰기: 끄기** (꺼야 `Text.txt`, `Text 1.txt`, `Text 2.txt`… 처럼 계속 새 파일이 생깁니다)
7. 아래 막대 **ⓘ**에서 실행 방식을 **즉시 실행**(또는 "실행 전 확인 끔")으로 둡니다. 이름은 `카드문자`로 저장.

> **만약 6단계 파일 저장이 같은 이름으로 덮어써지면**(inbox에 `Text.txt` 하나만 계속 바뀜): 텍스트 동작 앞에 `현재 날짜`→`날짜 포맷(yyyyMMdd-HHmmss)`→`난수(1000~9999)`를 넣고, 텍스트 뒤에 **이름 설정**(Set Name: `[날짜]-[난수].txt`)을 넣은 뒤 파일 저장을 하세요. 이름이 날짜로 시작하면 코드가 파일명으로 시각을 읽습니다.

## 7. 테스트 (10분)
1. 소액 결제(또는 승인 → 취소)를 합니다.
2. **파일** 앱 → iCloud Drive → Scriptable → CardLedger → **inbox**에 `Text.txt` 같은 파일이 생겼는지 → 열어서 **카드 문자 원문**이 보이는지.
3. **Scriptable → CardWidget → ▶** → **진단표**가 먼저 뜹니다.
   - `OK 우리다모아 +9,900원` / `OK … −9,900원`(취소)처럼 나오면 정상.
   - `카드 못 찾음`·`카드 모호`·`금액 못 찾음`이 있으면 그 줄이 보이게 캡처해서 보내 주세요.
4. 표를 닫으면 위젯 미리보기에서 합계가 반영됐는지 확인(승인 후 취소하면 다시 0으로 돌아옴).

## 8. 홈 화면에 위젯 붙이기 (3분)
1. 홈 화면 빈 곳 길게 누르기 → 왼쪽 위 **＋** → **Scriptable** → **가운데 크기** → **위젯 추가**.
2. 위젯 길게 누르기 → **위젯 편집** → **Script: `CardWidget`**.
3. **홈 화면용**으로만 쓰세요(잠금화면 금지: 금액 노출).

## 9. 이번 달 중간부터 시작했다면 — 시작 잔액 (선택, 1회)
자동화를 만들기 **전에** 쓴 금액은 위젯이 모릅니다(예: 10월 8일에 시작하면 10/1~10/7 사용분이 비어 있음). 카드사 앱의 **"이번 달(1일~오늘) 이용금액"** 으로 한 번만 맞춥니다. (문자의 `총누적`은 그달 누적이 아니므로 쓰지 마세요.)

1. 카드사 앱에서 각 카드의 **이번 달 1일~지금까지 이용금액**을 확인합니다.
2. 위젯 숫자(각 카드)와의 **차이**가 시작 잔액입니다. 예) 카드앱 120,000원, 위젯 9,900원 → 시작 잔액 110,100.
3. 메모 앱에 아래처럼 적어(숫자는 본인 값, 필요 없는 카드는 빼도 됨), 파일 앱의 `iCloud Drive/Scriptable/CardLedger/` 에 **`adjust.json`** 이름으로 저장합니다.
   ```
   {"2026-10": {"bc": 110100, "hd": 0, "sh": 20000, "wr": 5000}}
   ```
   - `bc`=BC바로, `hd`=현대ED3, `sh`=신한, `wr`=우리다모아. **달(`2026-10`)을 지정**했으니 **11월 1일부터는 자동으로 적용되지 않습니다.**
   - 위 숫자는 **모양을 보여 주는 예시**입니다. 본인 값으로 바꾸세요.
4. 11월부터는 아무것도 안 해도 됩니다(자동화가 만든 문자만으로 정확히 계산).

## 10. 평소 사용·유지
- 방금 쓴 결제가 위젯에 안 보이면 **위젯을 탭** → 앱에서 최신 값(진단표 → 미리보기)을 봅니다. 홈 화면 위젯 자체는 iOS가 갱신합니다(수 분~1시간, 즉시 보장 불가).
- **매월 1일 0시**에 자동으로 새 달 0부터 시작합니다. 할 일 없음.
- **25일경** 카드사 앱의 공식 실적과 한 번 대조하세요(카드사별 실적 제외 항목은 위젯에 반영되지 않습니다 — 위젯은 "이용금액" 기준).
- 전월에 결제한 건을 이번 달에 **취소**하면 이번 달에서 차감됩니다(취소 문자의 일시가 이번 달이므로). 카드사는 원래 결제한 달에서 차감하니 25일 대조에서 차이가 나면 `adjust.json`의 해당 월 숫자로 맞추세요.

## 11. 막혔을 때
| 증상 | 원인 | 해결 |
|---|---|---|
| "단축어 없음" 화면에서 막힘 | 단축어 탭을 보고 있음 | 맨 아래 **자동화** 탭 → ＋ → 메시지 |
| "보낸 사람을 구성하십시오" 문구가 안 사라짐 | 보낸 사람 미선택 | 6-1 참고. 번호 선택이 안 되면 연락처로 저장 후 선택 |
| 동작 검색에서 "단축어 입력"이 안 나옴 | 변수 이름이라 동작 검색에는 없음 | 6-2의 5번 `입력에서 텍스트 가져오기` 사용 |
| 문자 왔는데 inbox에 파일 없음 | 보낸 사람 번호 불일치(선택한 연락처의 번호가 실제 발신 번호와 다름) / 즉시 실행 아님 / 저장 위치 묻기 켜짐 | 6-1·6-2 재확인. 즉시 실행이 안 되면 문자 알림을 눌러 실행하는 반자동으로 사용 |
| 파일이 `Text.txt` 하나만 계속 덮어써짐 | 덮어쓰기가 켜져 있거나 이름이 고정됨 | 6-2의 "이름 설정" 대안 사용 |
| 파일은 있는데 내용이 비어 있음 | 문자 본문이 안 넘어옴 | 5번의 대안(`메시지의 세부사항 가져오기` → 콘텐츠)으로 바꾸고, 그래도 안 되면 파일 내용을 캡처해 보내 주세요 |
| 진단표 `카드 못 찾음` | 문자 머리말이 위 규칙과 다름 | 그 문자 캡처 보내 주세요 |
| 진단표 `금액 못 찾음` | 달러 외 통화(엔·유로 등) 또는 "원" 없는 형식 | 캡처 보내 주세요(달러는 자동 환산됨) |
| `Can't find variable …` 빨간 오류 | 코드 일부만 복사/옛 코드 | 전체 삭제 후 최신 코드 전체 다시 붙여넣기 |
| 위젯 "오류: inbox 폴더 없음" | 폴더 경로·철자 | 4번 재확인(iCloud Drive/Scriptable/CardLedger/inbox) |
| 금액이 카드사 앱과 다름 | 시작 잔액 / 카드사 실적 제외 항목 / 누락 문자 | 9번 시작 잔액, 진단표 확인, 25일 대조 |
| 월이 바뀌었는데 지난달 숫자가 보임 | 홈 위젯이 아직 갱신 전 | 위젯 탭 → 앱 화면은 이미 새 달 기준 |

## 12. 자동화가 정 안 될 때 대안
1. 문자 알림의 "실행"을 눌러 저장하는 반자동
2. 메시지에서 문자를 길게 눌러 복사 → 같은 단축어를 수동 실행
3. 특정 카드만 문자가 안 오면 그 카드만 수동 입력
4. 최소 구성: 카드사 앱의 공식 "이번 달 실적" 화면을 25일에 확인
