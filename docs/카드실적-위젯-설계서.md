# 카드 월 실적 아이폰 위젯 — 설계·검증·실행순서 (v2)

작성 2026-10-07 · iPhone 16 Pro · 카드: BC 바로 K-패스 / 네이버 현대카드 Edition3(ED3) / 신한카드 / 우리다모아카드
**요구사항(재정리)**: 4개 카드의 "이번 달 사용액 vs 혜택 구간"을 홈 화면 위젯 한 개로 본다. 취소는 −로 반영. **실시간 자동갱신은 불필요, 위젯을 눌러 새로고침할 때만 정확하면 됨.**

## 1. 결론

- **가능**. DB·서버·앱 개발 불필요. **단축어(기본) + Scriptable(무료) + iCloud Drive**.
- 아이폰은 앱이 SMS를 읽을 수 없어, 네이티브 앱을 만들어도 입구는 결국 단축어 → 이 조합이 가장 단순.
- 정확도는 "카드사 문자 형식"과 "단축어 즉시 실행 여부" 두 가지에 달려 있고, **둘 다 폰에서 10분이면 확인 가능**(§3).

## 2. 구조

```
카드 승인 SMS ─▶ 단축어 자동화(메시지 수신) ─▶ iCloud Drive/Scriptable/CardLedger/inbox/{시각}-{난수}.txt
                                                          (문자 1건 = 파일 1개, 원문 그대로)
Scriptable 위젯: 파일 전부 읽기 → 카드 분류 → 금액(취소는 −) → 이번 달(KST) 필터 → 카드별 합산
                 → 현재 구간 기준 "다음 목표"와 비교 → 위젯 표시 / 문자 속 "누적 이용액"과 교차검증(*)
```

설계 근거: ① 원문 보관 → 형식이 바뀌어도 코드만 고치면 과거 전체 재계산 ② 건별 파일 → 동시 문자 시 합계 덮어쓰기 유실 방지 ③ 월 필터 → 초기화 코드 없음 ④ 서버 없음 → 결제내역 외부 전송 없음.

## 3. 시작 전 관문 (순서대로, 하나라도 막히면 §7 대안)

| 관문 | 확인 방법 | 통과 기준 |
|---|---|---|
| 1. 단축어 **즉시 실행** | 단축어 > 자동화 > 새 개인 자동화 > 메시지 > 하단에서 "즉시 실행" 선택 가능한지 | 선택 가능 + "실행 시 알림" 끌 수 있음 |
| 2. 카드 4종 승인 SMS 수신 | 각 카드사 앱/고객센터에서 결제 문자 신청(유료인 곳 있음) | 실제 결제 후 "메시지" 앱에 도착 |
| 3. 필터 | 메시지 앱 > 필터 > 알 수 없는 발신자/프로모션 | 카드 문자가 일반함에 있음 |
| 4. 문자에 "누적" 포함 여부 | 문자 본문 확인 | 있으면 교차검증 활성, 없으면 `*`는 안 뜸(정상) |
| 5. 취소 문자 형식 | 소액 결제 후 취소 | "취소" 단어 + 금액 포함 |

## 4. 구축 순서 (이 순서대로 하면 됨)

**A. 폰 준비 (5분)**
1. 설정 > Apple 계정 > iCloud > 드라이브 ON, 목록에서 **Scriptable ON**
2. App Store에서 **Scriptable**(Simon Støvring, 무료) 설치 → 실행
3. 파일 앱 > iCloud Drive > Scriptable 안에 `CardLedger` 폴더 → 그 안에 `inbox` 폴더 생성

**B. 스크립트 설치 (5분)**
4. 이 저장소의 `scriptable/ledger-core.js`, `scriptable/CardWidget.js` 를 Scriptable에 각각 같은 이름의 스크립트로 붙여넣기 (이름: `ledger-core`, `CardWidget`)
5. `CardWidget`을 앱에서 실행 → 위젯 미리보기에 4카드가 0만으로 나오면 정상

**C. 단축어 자동화 4개 (카드별, 20분)** — 단축어 > 자동화 > + > 메시지
6. 조건: 메시지에 포함 → 카드별 키워드 (예: `BC` / `현대카드` / `신한` / `우리`). *실제 문자 샘플을 보고 발신번호로 거는 편이 더 정확*
7. **즉시 실행** 선택(관문 1), 알림 끔
8. 동작: ① 현재 날짜 ② 날짜 포맷(`yyyyMMdd-HHmmss`) ③ 난수 1000~9999 ④ 텍스트(1행 발신자 / 2행 현재 날짜(ISO 8601) / 3행~ 메시지 내용) ⑤ 파일 저장(iCloud Drive, 경로 `Scriptable/CardLedger/inbox/`, **저장 위치 묻기 끔**, 파일명 `날짜-난수.txt`)
9. 나머지 3개 카드는 자동화를 복제해 키워드만 변경

**D. 첫 검증 (10분)**
10. 소액 결제(또는 본인에게 카드문자 형식 문자 전송은 불가 → 실결제 권장) → 파일 앱 inbox에 txt 생성 확인, 열어서 3행 형식 확인
11. 위젯을 홈 화면에 추가: 길게 누르기 > + > Scriptable > 중간 > 편집 > Script `CardWidget`
12. 취소 결제 → 금액 감소 확인

**E. 문자 형식에 코드 맞추기 (내게 샘플 전달)**
13. 카드별 승인·취소·(있다면 부분취소·해외) 문자 샘플을 주면 `CARDS.match / exclude / CUMUL` 정규식을 확정, 테스트를 실문자로 교체
14. 신한·우리 구간 금액, 우리 제외항목 최종 확정

**F. 사용**
15. 평소에는 위젯을 보고, 방금 결제분이 안 보이면 **위젯을 탭**(앱이 잠깐 열려 갱신 + 리로드 요청)

## 5. 표시 규칙
- 빨강=다음 구간 미달, 초록=달성(전 구간 달성 시 마지막 구간 기준)
- 카드명 뒤 `?` = 구간 금액 미확인 임시값
- 숫자 앞 `*` = 문자 속 누적이용액과 내 합산이 다름(제외항목·누락 문자·형식 불일치 점검 신호; 누적이용액은 할부·현금서비스까지 포함하므로 `*`가 떠도 오류가 아닐 수 있음)
- 제목 옆 `⚠︎N` = 금액을 읽지 못한 문자 N건(해외결제 등)
- 취소: "취소" 포함 → −금액(부분취소 포함). 전월 건을 이번 달에 취소하면 이번 달에서 차감됨(한계)

## 7. 안 될 때의 대안 (우선순위)
1. 즉시 실행 불가 → 문자 도착 시 뜨는 알림을 한 번 탭해 실행(확인 1회), 또는 메시지에서 문자를 길게 눌러 복사 → 같은 단축어를 수동 실행
2. 특정 카드가 SMS를 안 줌 → 그 카드만 "금액 입력 → 파일 저장" 수동 단축어
3. Apple Pay로 결제하는 카드 → 단축어 "트랜잭션" 자동화(온라인결제 제외)
4. 기성 앱 병행: 뱅크샐러드·네이버페이·토스의 카드 실적 화면(앱 안에서 확인, 위젯은 4카드 지원 미확인)

## 8. 테스트
- 자동: `node test/ledger.test.js` — 승인/전액취소/부분취소/KST 월경계/금액 없는 문자/누적 이용액 파싱/구간 다음목표. **통과.** (문자 형식은 가정값)
- 위젯 스크립트는 문법 검사만 통과. **실제 렌더링은 폰에서만 확인 가능**
